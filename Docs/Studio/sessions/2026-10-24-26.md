## What went wrong, for next time
- **Labs froze whenever he used the Mac.** Fixed in the queue (Run In Background held for a run).
- **The app grant for Unity expires after 30 minutes idle,** so each return asks him again.
- **A "/" in a menu name makes a submenu in Unity.** The lab queue's menus now use "›".
- **A Python cache got committed in a builder's copy.** Removed; `__pycache__/` added to .gitignore.
- **One review agent's launch was refused once by the permission check.** It ran fine on the second try.
- **Pictures drawn in Pillow read as "AI art slop" to him.** Design is now shown in the game itself.
- **The cloud copy had no .gitignore.** Adding `__pycache__/` there created a two-line file, and deploying it replaced his real one. Library/, Temp/ and Logs/ then showed as new. It was caught before the commit: his file was put back from HEAD with the one line added, and the cloud copy now carries his real file.
- **Re-deploying a file from the same staging path sent the old copy.** A fix had to go up twice. Every deploy now uses a fresh path, and every deploy is checked by checksum on his Mac.
- **A locked screen stops everything but the running queue.** The queue now takes a run request from a file.
- **A builder's fix can look right in a simulation and fail in Unity** (Bench 8). The lab run is the judge; it was reverted the same afternoon.
- **A timing change can starve a day of its taught job** (the 14 s first-walk-in wait). The Day labs caught it; the taught repair is now guaranteed.
